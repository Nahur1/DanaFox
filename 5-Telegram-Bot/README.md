# 🤖 واژه‌یار — ربات تلگرام (VajeYar Telegram Bot)

ربات کامل آموزش لغات انگلیسی با **همهٔ امکانات اپلیکیشن**: لغات عمومی / آیلتس / تافل (سطح‌بندی از آسان به سخت)، فلش‌کارت تصویری با «فهمیدم / نفهمیدم» و تکرار ۱ روز تا ۱ ماه، تکرار فاصله‌دار (SM-2 + جعبهٔ لایتنر)، ۸ نوع آزمون، بازی، تلفظ صوتی، دیکشنری، لغات شخصی، آمار تصویری، دستاورد، یادآور و لغت روز — دوزبانه (فارسی / English).

> فقط کافی است **توکن** را بگذارید و اجرا کنید. پایگاه‌داده (SQLite) خودکار ساخته می‌شود.

### 🎨 اصول طراحی رابط (بر اساس راهنمای رسمی تلگرام)
- **چت تمیز:** ربات مثل یک اپ تک‌صفحه‌ای کار می‌کند؛ هر صفحه **همان پیام قبلی را ویرایش** می‌کند و پیام‌های تایپ‌شدهٔ کاربر بعد از پردازش پاک می‌شوند (صداها هم موقت‌اند).
- **دکمه‌های رنگی** Bot API (سبز = تأیید، قرمز = خطا/حذف، آبی = اقدام اصلی)، حداکثر ۵ دکمه در هر ردیف، دکمهٔ «بازگشت» و «خانه» ثابت.
- نقل‌قول (blockquote) برای آمار، بلوک **بازشونده** برای جزئیات زیاد، افکت 🎉 برای پایان جلسه و آزمون بی‌نقص.
- اعداد فارسی در حالت فارسی، راست‌به‌چپ کامل.

## 🚀 راه‌اندازی (۳ دقیقه)

### ۱) ساخت ربات در BotFather
1. در تلگرام به [@BotFather](https://t.me/BotFather) بروید ← `/newbot` ← نام و یوزرنیم ← **توکن** را کپی کنید.
2. برای حالت اینلاین: `/setinline` ← ربات را انتخاب کنید ← متن راهنما مثلاً `لغت را بنویسید…`
3. (اختیاری) `/setuserpic` برای عکس پروفایل — فایل `webapp/icons/icon-512.png` مناسب است.

> دستورها، توضیحات ربات (فارسی/انگلیسی) و دکمهٔ منو را **خود ربات هنگام اجرا تنظیم می‌کند**.

### ۲) تنظیم
```bash
cp .env.example .env      # در ویندوز: copy .env.example .env
# فایل .env را باز کنید و BOT_TOKEN را بگذارید (و ADMIN_IDS = آیدی عددی خودتان)
```

### ۳) اجرا — یکی از روش‌ها

**الف) سریع‌ترین:** لینوکس/مک: `./run.sh` — ویندوز: دوبار کلیک روی `run.bat`
(محیط مجازی می‌سازد، پیش‌نیازها را نصب و ربات را اجرا می‌کند.)

**ب) دستی** (Python 3.10 یا جدیدتر):
```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

**ج) Docker** (پیشنهادی برای سرور):
```bash
docker compose up -d --build
docker compose logs -f
```
داده‌ها در پوشهٔ `storage/` می‌مانند.

**د) systemd** (سرور لینوکس بدون Docker):
```bash
sudo useradd -r -m vajeyar && sudo cp -r . /opt/vajeyar-bot && sudo chown -R vajeyar /opt/vajeyar-bot
cd /opt/vajeyar-bot && sudo -u vajeyar python3 -m venv .venv && sudo -u vajeyar .venv/bin/pip install -r requirements.txt
sudo cp vajeyar-bot.service /etc/systemd/system/ && sudo systemctl daemon-reload && sudo systemctl enable --now vajeyar-bot
journalctl -u vajeyar-bot -f
```

### 🌐 سرور داخل ایران؟
اگر سرور به `api.telegram.org` دسترسی ندارد، در `.env` مقدار `PROXY` را بگذارید (مثلاً `socks5://127.0.0.1:1080`). بهترین گزینه سرور خارج از ایران است.
تلفظ با Microsoft Edge TTS (و در صورت قطعی gTTS) ساخته و **کش** می‌شود؛ هر تلفظ فقط یک‌بار تولید می‌شود.

### 📱 مینی‌اپ (اختیاری)
پوشهٔ `webapp/` همان اپ کامل است که با تلگرام هماهنگ شده. آن را روی یک آدرس **HTTPS** بگذارید (GitHub Pages، Netlify، Cloudflare Pages یا سرور خودتان) و آدرس را در `WEBAPP_URL` قرار دهید. دکمهٔ «📱 باز کردن اپ کامل» و دکمهٔ منوی تلگرام خودکار فعال می‌شوند.
برای سرو کردن از خود ربات: `SERVE_WEBAPP=true` و یک Nginx/Caddy با HTTPS جلوی پورت `8080`.
> پیشرفت مینی‌اپ روی دستگاه کاربر ذخیره می‌شود و از پیشرفت ربات جداست.

## 🧩 ساختار پروژه
```
bot.py                  نقطهٔ شروع (پروفایل ربات، polling، زمان‌بند)
vajeyar/
  config.py             تنظیمات از .env
  words.py              بانک لغات (از data/words_*.js — همان فایل‌های اپ)
  db.py                 SQLite (کاربر، پیشرفت، آمار روزانه، لغات شخصی، کش)
  logic.py              تکرار فاصله‌دار، رکورد، امتیاز، دستاوردها
  texts.py              متن‌های فارسی/انگلیسی
  ui.py                 دکمه‌ها و مدیریت صفحهٔ تک‌پیامی
  media.py              ساخت کارت تصویری، نمودار آمار، تلفظ
  online.py             دیکشنری و ترجمهٔ آنلاین
  scheduler.py          یادآور و لغت روز
  admin.py              /admin و /broadcast
  handlers/             core · study · mywords · play · inline · input
data/                   فایل‌های لغت (برای افزودن لغت همین‌ها را ویرایش کنید)
webapp/                 مینی‌اپ تلگرام
tests/                  شبیه‌ساز آفلاین (بدون توکن):  python tests/run_sim.py
```

**افزودن لغت به بانک:** در `data/words_*.js` هر خط: `word|pos|معنی فارسی|definition|example` (pos: n, v, adj, adv, prep, conj, phr).

## English quick start
1. Create a bot with [@BotFather](https://t.me/BotFather) → copy the token. Optionally `/setinline` to enable inline search.
2. `cp .env.example .env` and set `BOT_TOKEN` (and `ADMIN_IDS`).
3. Run: `./run.sh` (Linux/macOS), `run.bat` (Windows), `docker compose up -d --build`, or `pip install -r requirements.txt && python bot.py`.
4. Optional Mini App: host `webapp/` on HTTPS and set `WEBAPP_URL`.

Commands, bilingual descriptions and the menu button are configured automatically on start. Requires Python 3.10+; uses aiogram 3, SQLite, Pillow, matplotlib and edge-tts.
